# avvalent-marketplace
AVVALENT Marketplace एक multi-vendor eCommerce platform है जो Meesho की तरह design किया गया है। इसमें vendors, resellers और customers आसानी से products buy और sell कर सकते हैं।  यह platform scalable architecture पर आधारित है और इसमें product management, order system, admin control और reseller earning system शामिल है।
